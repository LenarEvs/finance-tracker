# CLAUDE.md — Правила работы с проектом Finance Tracker

Этот файл читается Claude Code автоматически при каждом запуске сессии.  
Правила обязательны к соблюдению во всех задачах в рамках этого проекта.

---

## Обязательные файлы проекта

### ARCHITECTURE.md

- Является **главным источником истины** об архитектуре проекта.
- **Любое изменение** схемы БД, структуры директорий, списка эндпоинтов или Docker Compose конфигурации должно **немедленно отражаться** в `ARCHITECTURE.md`.
- Перед добавлением новой таблицы, эндпоинта или сервиса — сначала обновить `ARCHITECTURE.md`, затем писать код.
- Не допускается расхождение между кодом и документацией.

### report/PROMPTS.md

- **Каждый новый промпт**, полученный от пользователя, должен быть добавлен в `report/PROMPTS.md`.
- Формат записи: порядковый номер (P-XXX), дата, назначение, полный текст промпта, краткое описание результата.
- Файл пополняется **до или во время** выполнения задачи, не после закрытия сессии.

### report/REPORT.md

- Ведётся как живой журнал разработки — **не итоговый документ**.
- После завершения каждого значимого этапа работы добавляется новая запись с:
  - описанием сделанного,
  - ключевыми решениями и их обоснованием,
  - удачными и неудачными шагами,
  - открытыми вопросами.
- Записи добавляются **по мере работы**, а не в конце проекта.

---

## Общие правила поведения

- Не создавать новые файлы-документы (README, заметки, планы), если пользователь явно не просил.
- Не добавлять комментарии в код, если причина не неочевидна.
- Не рефакторить код за пределами текущей задачи.
- Коммиты создавать только по явному запросу пользователя.
