## P-003 · 2026-06-08 · Архитектурное проектирование

**Назначение:** Создать файл ARCHITECTURE.md — полную архитектурную документацию приложения до начала написания кода.

**Промпт:**
```
Ты опытный fullstack-архитектор. Создай файл ARCHITECTURE.md для full-stack приложения
"Трекер личных финансов" со следующими требованиями:

Стек: FastAPI (Python), PostgreSQL, React + Typescript + Vite, Docker Compose.

Приложение должно поддерживать:
- Транзакции (сумма, дата, категория, описание, тип доход/расход, валюта, курс на момент)
- Справочник категорий (иконка, цвет, CRUD)
- Месячные бюджеты по категориям с прогресс-баром
- Повторяющиеся транзакции (APScheduler, ежемесячно)
- Импорт/экспорт CSV
- Дашборд: pie chart расходов, line chart за 6 мес, топ-5 категорий
- Audit log (кто, когда, что изменил, значения до/после)
- JWT авторизация, 2 пользователя изолированы друг от друга
- Мультивалютность

В ARCHITECTURE.md включи:
1. Схему базы данных (все таблицы, поля, типы, FK)
2. Структуру директорий проекта (backend/ frontend/ docker/)
3. Список всех REST API эндпоинтов с методами и описанием
4. Схему Docker Compose (сервисы, порты, зависимости)
5. План разработки по этапам

Формат — Markdown с заголовками и таблицами.
```

**Результат:** Создан [`ARCHITECTURE.md`](../ARCHITECTURE.md) — 7 таблиц БД, 39 эндпоинтов, структура директорий, Docker Compose схема, 9-этапный план разработки.
