## P-018 · 2026-06-10 · Починить журнал изменений (всегда пустой)

**Назначение:** Найти и устранить причину, по которой журнал изменений всегда отображает пустой список.

**Текст промпта:** «Сейчас не работает журнал изменений в проекте. Задача: Сделать так что каждое создание, редактирование и удаление транзакции, категории, бюджета фиксируется с указанием пользователя, времени и значений до/после; журнал доступен для просмотра»

**Результат:** Найден корневой баг: `GET /api/v1/audit-log` возвращал HTTP 500 `ResponseValidationError`. SQLAlchemy читает INET-поле из PostgreSQL как Python `IPv4Address`-объект, а Pydantic-схема объявляла `ip_address: str | None` — при попытке сериализации получала ошибку `Input should be a valid string`. Исправлено заменой типа на `IPvAnyAddress | None` с явным `field_serializer`. После рестарта бэкенда API вернул 5 записей.
